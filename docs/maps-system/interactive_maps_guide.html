3. Mathematical Formulations & Spatial Algorithms

Test the core mathematical algorithms running on the NivaaroFix dispatch engine below.

📐 1. Haversine Distance Formula

Calculates the great-circle surface distance between two latitude/longitude points.

Great-Circle Distance: 1.46 km
🧭 2. Great-Circle Forward Azimuth (Bearing)

Calculates angle in degrees ($0^\circ \text{ to } 360^\circ$) to dynamically rotate the directional navigation arrow.

Compass Heading Angle: 51° (North-East)

Mathematical Derivations:

Haversine Formula:

a = sin²(Δlat/2) + cos(lat1) * cos(lat2) * sin²(Δlng/2)
c = 2 * atan2(√a, √(1-a))
distance = R * c  (where Earth radius R = 6,371.0088 km)

Bearing (Heading):

y = sin(Δlng) * cos(lat2)
x = cos(lat1) * sin(lat2) - sin(lat1) * cos(lat2) * cos(Δlng)
bearing = (atan2(y, x) * 180 / π + 360) % 360

Exponential Smoothing (EMA):

Lat_smoothed = 0.70 * Lat_raw + 0.30 * Lat_prev
Lng_smoothed = 0.70 * Lng_raw + 0.30 * Lng_prev

60fps Cubic Ease-Out Marker Interpolation:

progress = Math.min(1, (currentTime - startTime) / duration)
ease = 1 - Math.pow(1 - progress, 3)
pos_current = pos_start + (pos_target - pos_start) * ease

🚀 Zero-Code Provider Switching:

The NivaaroFix codebase uses a Provider Adapter pattern. To deploy with Google Maps or Mapbox in production, you do not need to change any React components. Simply update .env with VITE_MAP_PROVIDER=google and your API key.
