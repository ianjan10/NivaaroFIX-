# Security Policy

NivaaroFix takes security and user privacy seriously.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability within NivaaroFix, please do **NOT** disclose it publicly via GitHub Issues.

Instead, please send an email to **security@nivaarofix.in** with:
- Description of the vulnerability and attack vector.
- Step-by-step reproduction instructions or proof-of-concept code.
- Impact assessment on customer or technician account integrity.

Our engineering team will acknowledge receipt of your vulnerability report within 48 hours and work with you on a coordinated disclosure timeline.
